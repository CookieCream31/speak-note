# 録画中のコンパクトな共有プレビュー・アイコン操作

最終照合: **2026-10-14**。[README](../README.md) · [操作](usage.md) · [現行構成の反映](operations.md#soniox-realtime-only)

## 表示と操作

共有プレビューは幅280px以下、高さ158px以下かつ画面高の20%以下で表示します。画像を切り取らず、共有している画面全体を確認できる小さな表示にします。文字起こし・要約・回答支援の閲覧領域を優先します。録音状態と経過時間はプレビュー上に残し、共有停止時は短い案内を表示します。マイク／共有音声だけの録音カードは従来のままです。

共有変更・マイク・終了はPC／タブレット／スマートフォンすべてで丸いアイコンだけのボタンです。通常48px、幅420px以下は44px。共有アイコンで画面を選び直し、マイクでミュートを切り替え、赤い停止アイコンで保存を開始します。マウスのツールチップ、読み上げ用の名前、ミュート状態、キーボードFocusを維持します。ミュートは斜線・赤色・赤枠で分かります。保存中の表示は残します。

縮小するのはCSSの表示だけです。録画用の元映像トラック、解像度別ビットレート、映像Part、共有変更、マイク合成、Live認識、保存、要約生成の方式は変更しません。画面上の縮小サイズで録画することはありません。両テーマの意味別色変数を使用します。

## 反映と確認

この表示変更はFrontendのみで、追加Migration・依存・環境変数はありません。ただし同時期のリアルタイムSoniox統一にはMigration **0031**とBackend／Workerの反映が必要です。最新ソースは[一式の反映手順](operations.md#soniox-realtime-only)を使ってください。

録音・録画・保存・実行中Jobが終了してから反映し、ブラウザを再読み込みします。共有する画面を選び、プレビューが小さく表示されること、共有変更・ミュート解除／ミュート・終了をアイコンから操作できることを確認します。停止後の音声・映像再生、Live原文・翻訳・要約が保持されること、共有変更後も録画が継続することを確認してください。スマートフォンと両テーマでもボタンが画面内に収まることを確認します。
