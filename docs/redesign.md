# speak-note リデザイン実装ガイド

最終更新: 2026-09-30。Claude Code がこの文書だけで実装できるように、デザイン案（Claude の Design キャンバス）の内容を文章と数値に落としたものです。
見た目の正解は `docs/redesign/mockups/*.dc.html` です。どのモックアップも静的な HTML なので、ブラウザで開くか、ソースを読んで余白・サイズ・色を確認してください（`{{c.xxx}}` は下の配色表のトークン、`[ ]` で囲んだ文字は仮の文言）。

## 0. 方針と守ること

- デザインの方向：**白・黒・グレーのモノクロに、差し色はエメラルド1色だけ**。赤はエラー（失敗・削除）と録画中の表示にだけ使う。影はほぼ使わず、線と余白で区切る。
- **既存の機能は削らない**。見た目・配置・部品の変更だけを行い、新しい機能（第4段階）は別の作業にする。
- `AGENTS.md` と `DESIGN.md` のルールに従う。仕様（DESIGN.md）と食い違う変更は勝手に行わず、確認する。
- 1段階（画面ごとの作業なら1画面）を1コミットにする。各コミットで次を実行して通す。
  - `cd frontend && npm test && npm run typecheck && npm run lint`
  - README と `docs/dark-mode.md` のうち、変更に関係する説明を同じコミットで更新する。
- 色は必ず `app/theme.css` のトークン経由で使う（`lib/theme-styles.test.ts` が CSS・TSX 内の色の直接指定を禁止し、文字と背景の明るさの差 4.5:1 以上を検査している）。
- 開発用 Compose は HMR で反映される。依存パッケージを追加したときだけ `sudo docker compose restart frontend` が必要。録画・録音中は再読み込みや再起動をしない。

## 2. 第2段階：全体の見た目（`globals.css` と共通部品）

1. **フォント**：`next/font/google` で `Geist`・`Geist_Mono`・`Noto_Sans_JP` を読み込み、`--font-sans: Geist, "Noto Sans JP", sans-serif` と `--font-mono: "Geist Mono", monospace` を定義する。Georgia・明朝体（ロゴ・見出し）と Inter の指定はすべてやめる。時刻・長さ・件数などの数字は `--font-mono`。
   - `next/font/google` はビルド時にフォントを取得する。Ubuntu からインターネットに出られない場合は、フォントファイルを `public/fonts` に置いて `next/font/local` にする。
2. **背景**：`body` の方眼背景（`--background-grid` の linear-gradient）を削除し、`background: var(--paper)` だけにする。
3. **文字サイズ**：7〜10px の指定をなくす。最小 11px、本文 14〜15px、補足 12〜13px。見出し：ページ 18px（ヘッダー）／会議タイトル 26〜28px／セクション 18px（すべて font-weight 600）。
4. **英字の大文字ラベルを削除**：`WORKSPACE`、`CAPTURE`、`MEETING DETAIL`、`MEETING NOTES`、`AI NOTES`、`ASK THIS MEETING`、`TOOLS`、`PROCESS`、`NEW MEETING`、`ORGANIZE`、`AI SETTINGS`、`01 / PROVIDERS` など番号付き見出し、`KNOWLEDGE WORKSPACE`、`LIVE ANSWER ASSIST`、`LIVE TRANSCRIPT`、`MEETING VIDEO`、`CHAPTER`。日本語の見出しだけ残す。
5. **アイコン**：⌂ ▤ ★ ☆ # ▦ ✦ ↑ ▣ ● ⌕ ◎ ↓ ⛶ ✎ ▶ などの文字記号を、線のアイコン（stroke 1.75、16〜20px）に替える。`lucide-react` を追加するのが簡単（追加後に frontend を再起動）。モックアップの SVG パスをそのまま使ってもよい。
6. **形**：角丸はボタン・入力 8px、カード・パネル 12px、ダイアログ 16px、ピル 999px。影はダイアログ・浮かぶ操作バー・メニューだけ。ボタンの高さは 32〜36px（スマホは 44px 以上）。
7. **状態ピル**：完了＝グレー（`--surface-hover` の面＋`--muted` の文字）、処理中（前処理・待機・文字起こし・AI解析）＝差し色の点＋文字、失敗＝`--danger`、録画中・録音中＝赤い点。

## 3. 第3段階：画面ごとのレイアウト

各画面の完成形は括弧内のモックアップ。どの画面も既存の操作・表示をすべて残すこと（下の「残すもの」）。

### 3-1 ホーム（`components/meetings-manager.tsx`／mockups: `Main.dc.html`）

- サイドバー（幅 240px、白）：ロゴ、ナビ（すべての会議・お気に入り＋件数、プロジェクト、AI設定）、タグ一覧（件数付き、押すと絞り込み、「管理」でタグ管理ダイアログ）、下部にワークスペース表示。
- ヘッダー（高さ 64px）：「ホーム」、検索欄、表示テーマ（システム／ライト／ダークの3択アイコン）、「＋ 新しい会議」（主要ボタン）。
- ホームの作成入口は「＋ 新しい会議」。取り込み方法カードは2026-10-11のUI整理で撤去し、作成ダイアログ内で3つの方法を選ぶ。初期モックアップのホーム上のカードは現在の表示には含めない。
- 「処理中・要確認」欄：`meeting.status` から処理中・失敗の会議を抜き出して表示（段階バーは 変換 → 文字起こし → AI解析 の3区間）。失敗は「開く」で会議画面へ。※ホームは今は自動更新しないので、表示の更新は第4段階（ポーリング追加）まで再読み込み頼り。
- 会議一覧：表の見出し行、「今週／先週」などの区切り、行（アイコン・タイトル・種類・タグ・作成日時・長さ・状態・お気に入り・操作メニュー）。選択行は `--blue-soft`。
- 一括操作：選択中だけ画面下中央に浮かぶ黒いバー（件数、タグを選択＋追加／解除、お気に入り／解除、削除、選択解除）。
- 残すもの：検索（タイトル・種類・状態・タグ）、並び順3種、お気に入り切替、タグ絞り込み、行メニュー（開く・タイトル変更・タグ付け外し・削除確認）、一括操作5種、空状態の文言、読み込みエラー表示。

### 3-2 会議詳細（`app/meetings/[meeting_id]/page.tsx`、`meeting-workspace.tsx` ほか／mockups: `Meeting.dc.html`、`MeetingPanels.dc.html`）

- ヘッダー（56px）：ロゴ、パンくず（会議一覧 / 会議名）、表示テーマ、AI設定。
- タイトル部：会議名、状態ピル・種類・日時・長さ・ファイル情報の1行、設定ボタン列（プロジェクト／この会議で使うAI／話者数：押すと今の選択 UI を開く）、「処理状況：すべて完了 ▾」（押すと今の JobStatusPanel を展開）。右に「ダウンロード ▾」（文字起こしテキスト・動画／音声）と「要約を再生成」（主要ボタン、今の SummaryRegenerationButton のダイアログを開く）。
- 本体を2列にする（左 620px／右 残り）。
  - 左：プレイヤー（既存の TranscriptMediaPlayer。見た目だけ変更）の下に、「チャプター｜文字起こし」のタブ（黒地が選択中）。
    - チャプタータブ：サムネイル（第4段階までは暗いグレーの四角）＋タイトル＋開始時刻、右下にチャプターの長さ。再生中は面を `--surface-hover`、時刻ラベルを差し色、サムネイル下端に進み具合のバー。押すとその位置から再生。
    - 文字起こしタブ：今の TranscriptDocument（自動追従、タイムスタンプ、話者名の変更、文字単位のハイライト、「修正」＝今の文字起こし修正フォーム）。チャプターの切れ目に区切り線（時刻・タイトル・線）。
  - 右：タブ「要約／質問／検索・ツール」（下線タブ）。今のタブから「文字起こし」を左へ移した形。
    - 要約：AI議事録の見出し、「全編／重要箇所だけ再生」、版の履歴、その他メニュー（外部AIで作成＝ManualAIImport）。項目は1行ずつ：本文、状態（AI生成・編集済み・確認済み）、再生範囲ボタン、「根拠となる発言 N件」（開くと発言一覧）、ホバー／選択時に「編集」「確認済みにする」。Action Item は担当・期限を表示（完了チェックは付けない）。テンプレート使用時は TemplateAnalysisCards を同じ見た目で。
    - 質問：今の MeetingQuestionPanel（吹き出しは右寄せのグレー、AI回答は枠なしで根拠チップ付き）。
    - 検索・ツール：今の MeetingToolsPanel。中のタブ（検索・ブックマーク・話者名・タイムライン）はセグメント型にする。
- 画面幅 1279px 以下（既存のブレークポイント）では1列に並べ、プレイヤー → チャプター／文字起こし → 要約タブの順。
- 残すもの：リアルタイム版／高精度版の切替リンク、字幕・画質設定、キーボード操作（Space・J・K・L・F・M・C など）、録画中・処理中の各表示、リアルタイム版の注意文。

### 3-3 新しい会議（`meetings-manager.tsx` のダイアログ／mockups: `NewMeeting.dc.html`）

- 幅 560px。取り込み方法は3つの選択カード（選択中は黒枠）。選んだ方法で下が切り替わる：ファイル＝ファイル選択欄、画面共有＝「共有する画面・ウィンドウを選択」＋選んだ画面名、マイク＝説明文。画面共有・マイクではマイク開始状態をスイッチで表示。

- 下部の固定フッター：キャンセル／「作成してアップロード」（方法により文言が変わる。今の文言のまま）。

### 3-4 録画・録音中（`live-meeting-recorder.tsx`、`answer-assist-panel.tsx`、`realtime-analysis-panel.tsx`／mockups: `LiveMeeting.dc.html`）
